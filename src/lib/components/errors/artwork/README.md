# Графіка гри

Ці SVG — джерела графіки, які реально використовує гра. Відкривайте їх у Inkscape
або імпортуйте у Figma. Зберігайте зміни під тим самим ім’ям і перезавантажуйте локальну сторінку.
Файли підключаються через Vite `?raw`, без окремих мережевих запитів до картинок.

Чотири пози містять оригінальні контури з наданих SVG без зміни точності координат.
Кожна поза — готовий вовк із руками й кошиком: гра малює лише вибрану позу,
без додаткового кошика чи віддзеркалення.

## Як експортувати

- Зберігайте **координати та `viewBox`**: гра використовує локальні координати SVG,
  а не масштабує малюнок до розміру сторінки. Не обрізайте полотно автоматично.
- Чотири пози вовка мають власні координати. Єдиний масштаб `0.6`, опорні точки
  горловини та компенсація різних відступів полотна задаються в
  [../egg-wolf.ts](../egg-wolf.ts). Не змінюйте рамку SVG під час експорту.
- Горловина розміщується на 10 одиниць нижче останнього яйця; точки ловлі
  `(233,176)`, `(407,176)`, `(233,281)`, `(407,281)` і механіка гри не змінені.
- Основний колір `#30372c`, світлі деталі `#a5aa8d`.
  Чорний колір наданих SVG перетворюється на `#30372c` під час малювання.
  Неактивні пози автоматично стають `#858970`, світлі деталі приховуються.
- Поточний синхронний Canvas-рендерер підтримує `svg`, `g`, `path`, `ellipse`, `circle`,
  атрибути `fill`, `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`
  і трансформації `translate`, `scale`, `rotate`, `matrix`.
- Перед експортом перетворіть прямокутники, текст та інші фігури на контури (`path`).
  Стилі експортуйте як SVG-атрибути, не CSS-класи чи `style`.
  Не використовуйте маски, фільтри, градієнти, `use`, зовнішні зображення або шрифти:
  цей рендерер їх не підтримує.

Розташування, цифри, доріжки й написи залишаються в [../egg-display.ts](../egg-display.ts).
Завантаження та малювання SVG — [../egg-artwork.ts](../egg-artwork.ts).
Корпус консолі й кнопки — [../CircuitError.svelte](../CircuitError.svelte).
