# Pay — Ultra-Fast Svelte 5 Checkout Application

Платіжний чекаут нового покоління у стилі **Apple App Clip / Apple Pay** на базі **Svelte 5 (Runes)** та **Vite 8**.

## Особливості архітектури

1. **Динамічні сценарії, керовані з бекенду (JSON)**:
   - Всі сценарії (`fixed`, `open_amount`, `table`, `delivery`, `donation` тощо) конфігуруються через JSON (`scenarios.json` або `order.scenario_config`).
   - Бекенд може передавати як тип сценарію, так і кастомні налаштування (тексти кнопок, підказки, методи доставки, швидкі суми тощо).
   - Для додавання нового сценарію достатньо описати його схему в JSON без зміни ядра застосунку.

2. **Статична шторка вибору банків (`BankSheet.svelte`)**:
   - Шторка вибору банків є універсальною та фіксованою для всіх сценаріїв.
   - Містить 3D-карусель карток з апаратно-прискореною перспективою (`perspective(900px) rotateY(...)`), динамічний розрахунок комісій (наприклад, Privat24 0.5%), екран швидкого пошуку серед усіх банків, реквізити мерчанта (IBAN, ЄДРПОУ), ініціалізацію платежу через Worker API, запуск застосунків банку (deep-link fallback) та опитування статусу платежу.

3. **Надшвидкодія (Ultra-Fast Performance)**:
   - Розмір критичного бандла: **~33 KB JS (gzipped) та ~6 KB CSS (gzipped)**.
   - Час збірки: **~1 секунда**.
   - Немає важких блокуючих залежностей на старті — бібліотеки Supabase Realtime та Google reCAPTCHA v3 завантажуються асинхронно та ліниво лише при необхідності.
   - Анімований одометр на CSS-колонках без перерендеру всього дерева.

## Сценарії за замовчуванням

- **`fixed`** (`?sc=fixed` або `?sc=1`): Фіксований рахунок, картка замовлення, підтримка промокоду з візуальним дисконтом, перехід до оплати.
- **`open_amount`** (`?sc=amount` або `?sc=2`): Оплата на касі / вільна сума, цифрова тактильна клавіатура, перехід до оплати.
- **`table`** (`?sc=table` або `?sc=3`): Столик ресторану. Початковий стан очікування («Готуємо рахунок») зі слухачем Realtime/BroadcastChannel -> після надходження чека з'являється TTL-таймер та кнопка оплати.
- **`delivery`** (`?sc=delivery` або `?sc=4`): Візард доставки Новою поштою (Огляд -> Отримувач -> Вибір відділення/поштомату/кур'єра) з автоматичним перерахунком суми замовлення.

## Команди для розробки та збірки

З кореня репозиторію `corex`:
```bash
npm run dev:pay      # Запуск Vite dev сервера
npm run build:pay    # Збірка продакшн-бандла в dist/
npm run check:pay    # Перевірка типів Svelte 5 та TypeScript
npm run test:pay     # Запуск автоматичних юніт-тестів
```
