# RAHUNOK Ecosystem Portal (`apps/main`)

Інтерактивна вітрина та хаб навігації по всіх сервісах екосистеми **RAHUNOK / COREX**.

## Можливості

1. **Повний каталог 11 сервісів екосистеми**:
   - **Apex Portal (Landing)**: Головна вітрина, калькулятор економії, сценарії оплат.
   - **Merchant Dashboard**: Кабінет мерчанта, виставлення рахунків у 2 кліки з клавіатури, проформи, реквізити.
   - **Support Cabinet**: Діагностика, підтримка та моделювання клієнтських сесій під UUID.
   - **Corex Workflow Engine**: Графи станів, автоматизація, AI-воркери, Time-Travel дебаг.
   - **Pay & Checkout**: Клієнтський платіжний екран, deeplinks у банки (Monobank, Privat24), чайові, split payment.
   - **Merchant POS App**: Мобільна каса, Telegram WebApp, «рідка оплата» свайпом, швидкі товари.
   - **Delivery & Logistics**: Інтеграція Нова Пошта & Meest, GPS-пошук поштоматів, автодоставка в рахунку.
   - **QR Studio**: Динамічні QR стандарту НБУ 003, векторний друк, художні QR з логотипом.
   - **Platform DAC7**: B2B маркетплейс, директива DAC7, сплит-виплати, перевірка контрагентів.
   - **Bank Connectors (Conf)**: Синхронізація банківських виписок, звірка оплат, моніторинг Open API.
   - **API Gateway & Core Workers**: Високонавантажений Cloudflare Edge бекенд, 30+ OpenAPI методів.

2. **Перемикач оточень**:
   - `rhnk.to` (Production)
   - `rhnk.pp.ua` (Staging / Test)
   - `localhost` (Development порти: 5173, 5174, 5176, 5178, 5179, 5180, 5181, 8787)

3. **Архітектурний ланцюг обробки платежу**:
   - Візуалізація руху даних: `Клієнт` ➔ `QR/Delivery` ➔ `Edge API` ➔ `Pay` ➔ `Corex` ➔ `Bank Sync`.

4. **Швидкі дії**:
   - Перехід до сервісу в один клік у новій вкладці.
   - Копіювання посилання в буфер обміну.
   - Пошук за назвою, технологіями та тегами.
   - Фільтрація за категоріями.

## Запуск

### Запуск через Vite:
```bash
npm run dev:main
# або
cd apps/main && npm run dev
```
Порт за замовчуванням: `http://localhost:5172`.

### Автономне відкриття:
Файл `index.html` містить автономний fallback і відкривається напряму в будь-якому сучасному браузері без запуску локального сервера.
